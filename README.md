# ringside-site
Public website for the Ringside: Horse Show Scores iOS app.

- `privacy.html` is the privacy policy (App Store Connect privacy policy URL).
- `index.html` is a minimal landing page.

Publish with GitHub Pages (Settings > Pages > Deploy from branch `main`, folder `/ (root)`). The policy is then at https://kobrinsam.github.io/ringside-site/privacy.html.
